# Nature Impact

Mobile-first React app for one small environment-friendly action every day.

**Stack:** React · Vite · Tailwind CSS · Material UI  
**Data:** Frontend-only (localStorage) · 100+ static actions

## Run

```bash
npm install
npm run dev
```

Open the URL shown in the terminal. On desktop you'll see a phone frame; on a real phone it fills the screen.

## Screens

- **Onboarding** — name, location, interests, reminder time
- **Today** — daily action, I Did It / Not today
- **Completion** — estimated impact, points, streak
- **Impact** — dashboard, milestones, category breakdown
- **History** — past actions with filters
- **Explore** — searchable action library
- **Profile** — preferences and reset

## Product principle

Easy → Positive → Measurable → Repeatable  
Impact values are **estimates**, not exact science.
